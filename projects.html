MOOving Up

2023

MOOving Up is a single-player action adventure game that combines 2D sprites with 3D physics. Pilot a UFO, fight bosses, acquire power ups, and collect as many cows as possible. Developed with a team of 5.Created using Unity and C#. Utilized GitHub for version control and managed the project on JIRA.
